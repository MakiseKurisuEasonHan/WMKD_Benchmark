开始 WMKD_Benchmark 新实验设计阶段：

Bc = SAME-LINEAGE ONLINE LOGIT DISTILLATION

当前只做：

PN-FP Llama→Llama Logit-KD Pilot

目标：
先验证标准 same-tokenizer online logit distillation 是否在当前 RTX PRO 6000 96GB 上稳定可行，并实测训练速度，从而估算完整 Bc campaign 时间。

本轮禁止直接跑完整7500步。
先完成：
2-step smoke
→ 100-step timing/stability pilot
→ report
→ 等用户决定是否进入full run。

2. DATASET
==================================================

使用 PN-FP 原 same-lineage Ba 的 canonical frozen ordinary 20k。

不要重新生成 Teacher QA。
不要重新 paraphrase。
不要使用 Bb targets。

目标是保证：

Ba:
same frozen 20k
→ hard response CE only

Bc:
same frozen 20k

尽量让唯一核心变化为：
logit supervision。

- same Ba formatter/template
- dataset provenance记录

==================================================
3. TRAINING OBJECTIVE
==================================================

只在 assistant response tokens 上计算loss。

Prompt/system/user tokens：
MASKED

Assistant response tokens：
CE + KD

定义：

L_total =
0.5 * L_CE
+
0.5 * T^2 * KL(
    softmax(Teacher_logits / T)
    ||
    softmax(Student_logits / T)
)

Temperature:
T = 2.0

CE weight:
0.5

KD weight:
0.5

本轮只是pilot。
不要调参寻找更强watermark transfer。

不要改变：
- T
- CE/KD ratio
除非出现明确数值/稳定性问题，并先报告。

==================================================
4. TEACHER EXECUTION
==================================================

Teacher必须：

- eval mode
- frozen parameters
- requires_grad=False
- torch.inference_mode() / no_grad
- no optimizer
- no backward
- no parameter update

Teacher只负责每个batch forward生成soft logits。

禁止：
- 保存20k full logits到磁盘
- offline logit dump
- teacher update

==================================================
5. STUDENT EXECUTION
==================================================

Student：

fresh clean Llama initialization

full-parameter training

保持尽量与原Ba一致：

- BF16
- LR = 1e-5
- effective batch size = 8
- seed = 42
- same scheduler/warmup semantics if historical Ba fixed
- same max sequence length
- same chat template
- same answer masking
- no LoRA
- no quantization
- no resume

==================================================
6. MEMORY-SAFE KL IMPLEMENTATION
==================================================

重点避免 full-vocab logits 导致显存爆炸。

要求：

- Teacher logits尽量BF16保存
- Student logits正常BF16
- KL计算可用FP32 accumulation
- 仅对assistant response token positions做KD
- prompt positions不要参与KL
- Teacher logits用完立即释放
- 必要时对sequence positions做chunked KL
- 不要把整batch×seq×vocab长期复制成多个大tensor
- 避免不必要clone/contiguous副本

如果需要chunked KL：
允许，只要数学结果等价于完整assistant-token KL。

记录chunk size。
