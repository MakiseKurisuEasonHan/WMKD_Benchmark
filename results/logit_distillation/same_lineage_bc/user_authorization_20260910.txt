D. UNIVERSAL LOGIT-KD OBJECTIVE
==================================================

对所有 6 个 run 使用完全相同的 KD protocol。

MASKED

assistant response tokens:
CE + KD

Temperature:
T = 2.0

Loss:

L_total =
0.5 * L_CE
+
0.5 * T^2 * KL(
    Teacher_distribution || Student_distribution
)

Teacher || Student

- epochs
