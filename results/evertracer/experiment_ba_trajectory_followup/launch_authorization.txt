==================================================
7. 方法特定 detector
==================================================

EverTracer
- exact frozen verification members/nonmembers
- exact frozen reference model
- exact frozen neighborhoods
- exact aggregation code
- record:
  - member-oriented AUC
  - TPR at empirical FPR <= 0.05
  - FPR
  - threshold
  - errors/nonfinite scores
- 不重新校准 detector

CTCC
- exact frozen WMKD operational detector
- generated_answer.strip() == "IAMALIVE"
- case sensitive
- record:
  - trigger activations / total
  - suppression activations
  - normal activations
  - combined negative false activations
  - generation errors
- 保留 limitation：
  WMKD operational equality detector is not the official CTCC detector

iSeal
- exact frozen registered-secret detector
- same registered set
- same BLEU semantics
- same threshold
- record:
  - success count / total
  - success rate
  - mean BLEU
  - median BLEU
  - detector errors

SCW
- exact frozen statistical detector
- same frozen query set
- same permutation/order
- alpha = 0.001
- lower p-value = stronger fingerprint evidence
- record:
  - p-value
  - fingerprinted yes/no
  - query count
  - detector errors
- no threshold change
