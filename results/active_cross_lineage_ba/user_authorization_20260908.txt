C. FIRST: minimal applicability + clean-Qwen baseline audit
==================================================

不要先训练。

先对 5 个 active detector 做最小、关键、read-only applicability audit。

目标：

判断每个 detector 对 Qwen 是否属于：

SUPPORTED
ADAPTABLE_WITHOUT_SEMANTIC_CHANGE
NOT_APPLICABLE

必须优先读取：
- 当前项目已有正式代码
- 原实验 detector 实现
- frozen detector assets/config
- 原论文/官方代码中已经归档的 detector semantics

不要为了跨架构人为修改公式。

逐方法检查：

--------------------------------------------------
1. PN-FP
--------------------------------------------------

重点确认：
- fingerprint key 是否文本级 / token-string 级
- expected target 是否依赖固定 Llama token IDs
- Qwen tokenizer 是否能在不改变科学语义的情况下执行同一 detector

如果原 detector 可以对生成文本按同一 secret fingerprint 判定：
SUPPORTED / ADAPTABLE_WITHOUT_SEMANTIC_CHANGE

如果 detector 根本绑定 Llama-only token IDs，且必须重新定义 secret：
NOT_APPLICABLE

绝对不要重新生成 PN-FP secret fingerprint。

--------------------------------------------------
2. EverTracer
--------------------------------------------------

确认 detector 是否只依赖：
- query
- output behavior
- perturbation/output comparison

如果需要 architecture-specific hidden-state hooks：
判断是否存在原定义允许的跨架构执行方式。

不要重新定义 detector。

--------------------------------------------------
3. CTCC
--------------------------------------------------

优先按原 frozen detector：

trigger prompt
→ generated_answer.strip() == "IAMALIVE"

case-sensitive exact match。

同时跑 frozen negatives。

预期大概率 SUPPORTED。

不要改：
- trigger set
- exact string
- threshold
- generation rule

--------------------------------------------------
4. iSeal
--------------------------------------------------

重点检查原 verification interface：

inputs_embeds
embedding dimension
tokenizer
embedding matrix
registered plaintext
registered secret

如果原 detector 依赖 Llama embedding topology，
且无法在 Qwen 上保持原科学语义：
NOT_APPLICABLE

绝对不要为了 Qwen：
- 投影 embedding
- 改 dimension
- 重新注册 watermark
- 重新训练 detector
- 改 threshold

如果官方定义本身允许文本级验证，才允许执行。

--------------------------------------------------
5. SCW
--------------------------------------------------

确认原冻结 detector 是否能基于 Qwen 输出执行完全相同的统计检验。

保持：
- frozen eval prompts
- original statistic
- original significance alpha
- original detection rule

P. Important interpretation boundary
==================================================

不要把：

detector negative

自动写成：

watermark completely erased

- no detectable transfer
- detector not applicable
- weak partial acquisition
- non-detection under frozen rule
- runtime failure

也不要因为 Qwen Student 没有水印就说：
“distillation removed the watermark”

因为 Student 是 fresh Qwen，
更准确的是：

“the watermark was not acquired / did not transfer under cross-lineage behavioral extraction.”
