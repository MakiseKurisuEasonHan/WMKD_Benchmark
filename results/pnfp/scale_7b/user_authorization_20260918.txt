四、7B 模型选择原则
━━━━━━━━━━━━━━━━━━━━━━

本轮目标是 Llama 7B 同源实验。

优先目标：
canonical Llama-2-7B HF-format model，尽量使用原版或可验证等价镜像。

下载原则：

1. 优先国内可访问源
2. 优先 ModelScope
3. 如果 ModelScope 当前不可用或非常慢，可以寻找其他国内镜像
4. 可以使用 HF mirror / 国内 CDN / 可信第三方镜像作为 transport
5. 但是“下载源可以换，模型本身不能静默换”

禁止为了方便换成：
- Chinese-Llama 二次训练模型
- Atom 等额外 continued-pretraining 模型
- GGUF
- GGML
- AWQ
- GPTQ
- AQLM
- 4-bit / 2-bit 量化模型

正式 backbone 应为标准 Transformers 可训练格式。

如果不能获取 canonical repo，可使用可信等价镜像，但必须记录：
- source
- upstream identity
- config
- tokenizer
- architecture
- model file list
- revision / commit（如果可得）
- provenance

只做必要等价性检查，不要无限审计。
