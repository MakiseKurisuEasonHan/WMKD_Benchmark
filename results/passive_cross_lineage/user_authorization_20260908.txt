==================================================
6. Passive detector rules
==================================================

--------------------------------------------------
LLMPrint
--------------------------------------------------

复用冻结 fingerprint prompts / suffixes / bits / threshold。

输出：
- matched bits / 200
- bit accuracy
- threshold
- detected yes/no
- errors

如果 Qwen tokenizer/architecture 使某些 fingerprint prompt formatting 需要正常 chat adaptation：
允许使用 Qwen 官方 template，
但 fingerprint content 不变。

--------------------------------------------------
REEF
--------------------------------------------------

复用冻结 probe inputs 与 CKA semantics。

如果 layer indexing 不同：
必须先判断论文/当前实现是否允许 cross-architecture comparable layer selection。

优先：
- 最深 comparable normalized layer position
或
- 原 detector 明确支持的层定位方式

不能凭感觉选层。

如果 cross-architecture CKA 在现有 frozen detector 语义下不成立：
标记 NOT_APPLICABLE_CROSS_ARCH。

输出：
- CKA
- threshold
- detected yes/no
- exact layers used
- shape alignment rule

--------------------------------------------------
HuRef
--------------------------------------------------

首先验证：
Qwen 是否具有与 HuRef detector 要求一致/可映射的 Wq/Wk/Wv/Wo/Wu/Wd 等结构。

如果官方/当前实现允许 generic Transformer projection mapping：
按冻结 semantics 做。

如果 HuRef 依赖 Llama-specific exact tensor topology：
不要硬套 Qwen。

必须明确：
SUPPORTED / NOT_APPLICABLE

输出：
- ICS
- threshold
- selected layers
- selected matrices
- mapping rule

--------------------------------------------------
AWM
--------------------------------------------------

检查 Qwen attention projection 结构是否支持冻结 Wq/Wk weight geometry detector。

如果 projection shapes 可合法比较：
运行官方 CKA semantics。

如果必须改变 detector 数学定义才能适配：
不允许。

输出：
- Wq CKA
- Wk CKA
- aggregate score
- threshold
- detected yes/no

--------------------------------------------------
ZeroPrint
--------------------------------------------------

ZeroPrint 更偏 behavior/local-response fingerprint，
原则上最适合 cross-architecture。

复用：
- frozen prompts
- frozen perturbations
- frozen scoring
- frozen rescaling
- frozen threshold

输出：
- raw Pearson
- rescaled score
- threshold
- detected yes/no

11. Scientific interpretation rules
==================================================

如果出现：

same-lineage Base/high
same-lineage Ba/high
cross-lineage Qwen low
cross-lineage Ba low

则只能说：

“Results support a strong shared-lineage / initialization contribution to passive fingerprint retention.”

不要直接说：
“证明 passive watermark 完全没被蒸馏传递。”

如果：

cross-lineage clean low
cross-lineage Ba 显著升高

则说明存在：

“evidence consistent with behavioral distillation inducing partial cross-lineage fingerprint similarity.”

仍不做 universal causal claim。
